# HealthCare Sierra Leone

## Community Healthcare Reporting and Triage Support System

### Project Description

HealthCare Sierra Leone is a community healthcare reporting and triage support system designed to demonstrate how programming logic can be used to organize basic healthcare information, assess urgency levels, and provide appropriate healthcare recommendations.

The system is designed as an educational project and does not provide medical diagnosis. Its purpose is to demonstrate algorithms, pseudocode, flowcharts, decision structures, validation, repetition, and modular design.

## Problem

People may experience health problems without knowing how urgent their situation may be or when they should seek professional healthcare attention.

HealthCare Sierra Leone provides a logical approach for processing basic health information and identifying an appropriate urgency level.

## Proposed Solution

The system collects:

- Age
- Main symptom
- Temperature
- Symptom severity

It validates the information and classifies the reported situation into four urgency levels:

- LOW
- MODERATE
- HIGH
- EMERGENCY

The system then provides an appropriate recommendation.

## Urgency Levels

| Level | Recommendation |
|---|---|
| LOW | Monitor the situation and consider routine healthcare advice. |
| MODERATE | Contact or visit a healthcare professional. |
| HIGH | Seek medical attention as soon as possible. |
| EMERGENCY | Seek emergency medical assistance immediately. |
